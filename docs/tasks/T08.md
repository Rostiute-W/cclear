## 目标
完成执行前的预览确认流程、历史页，以及空间分析页的 treemap。

## 实现要点
1. 组件 `PlanPreview`（`src/components/PlanPreview.tsx`），输入 planId：
   - 每条规则一行：名称、恢复方式标签（可再生 / 永久删除 / 隔离 / 不可撤销命令）、文件数、占盘大小、逻辑大小、构建时跳过的数量（可展开查看原因）。
   - 点击某条规则时分页显示条目（每页 200 条，通过 `plan_items` 获取）。
   - 汇总四个口径：逻辑大小、占盘大小、预计可回收（= 占盘大小，并附注“硬链接或被占用的文件可能不会释放空间”）、执行后观测到的空闲变化（执行后才显示）。
   - 包含 `IrreversibleFile` 规则时，必须勾选“我了解这些文件将被永久删除”才能确认。
   - 执行中显示进度，提供“取消”按钮（提示“已删除的文件不可恢复”）。
   - 执行后显示每条规则的删除数、跳过数和跳过原因，以及执行前后的剩余空间。
2. 历史页：列表列为时间、规则、释放空间、跳过数；点击查看详情。数据来自 `history_list` 返回的 `PlanSummary`，需要时可以在 core 中补充详情读取函数。
3. treemap（空间分析页，新增“图形”页签，与列表共用面包屑）：
   - 引入 `d3-hierarchy`，使用 `treemapSquarify`。
   - 只布局当前节点的直接子节点，按 allocated 取前 60 个，其余合并为“其他”。
   - 用 SVG 绘制矩形并显示标签，悬停时显示提示，点击进入该子目录。
   - 窗口尺寸变化时重新布局。
