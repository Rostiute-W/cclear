## 问题
1. **用户名后面接中文标点时没有脱敏（隐私）**。Droid 用只读工具对本机 68 条规则调用 `ai::rule_messages`，补充问题写成“我的桌面是 C:\Users\<名>\Desktop，用户名 <名>，能删吗”：路径都替换成了 `%USERPROFILE%`，但“用户名 <名>，”里的用户名原样发出。原因是 `crates/cclear-core/src/ai/mod.rs:498` 的 `is_boundary` 只认 `\`、`/`、空白和引号，中文逗号、冒号、括号、句号以及紧挨着的汉字都不算边界。
2. 设置页说明文字（`src/pages/Settings.tsx:99-102`）与 T20b 任务书要求的文案不一致，少了“替换为 %USERPROFILE% / <用户名>”和“只有当前 Windows 账号能解开”。

## 实现要点
1. `is_boundary` 改为：**除 ASCII 字母、ASCII 数字、`_`、`-` 以外的任何字符都算边界**（包括 `.`、中英文标点、汉字、空白、引号、分隔符）。这样 `Alicex`、`Alice_1`、`Alice-PC` 仍不被误改，而 `Alice，`、`（Alice）`、`用户名Alice能删吗`、`Alice.bak` 都会替换。更新函数上的注释说明这个规则和原因。
2. `tests/ai.rs` 的 `redact_hides_profile_and_username` 里追加断言（不新增测试函数）：
   - `用户名 Alice，能删吗` → `用户名 <用户名>，能删吗`
   - `（ALICE）` → `（<用户名>）`
   - `用户名Alice能删吗` → `用户名<用户名>能删吗`
   - `D:\Backup\Alice_1\y`、`D:\Backup\Alice-PC\y` 保持不变
3. 设置页 `card-lead` 改成下面这段（原样）：“只在你点击‘问 AI’时才联网，请求只发往上面填写的地址。发送前会把用户目录替换为 %USERPROFILE%、把用户名替换为 <用户名>。API Key 用 Windows 加密保存，只有当前 Windows 账号能解开。AI 的回答仅供参考，不会自动执行任何清理。”
