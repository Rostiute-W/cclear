# T04 规则目录与候选解析

- 里程碑：M1
- 依赖：T03

> 执行者先阅读仓库根目录的 `AGENTS.md`。本文件之外的需求一律不做。

## 目标
把 `docs/plan-final.md` §4 的规则表实现为内置规则目录，并实现候选解析：解析路径、统计大小、判断状态。本任务只做分析，不做执行。

## 实现要点
1. `model.rs` 新增以下枚举：
   - `Tier { Safe, Caution, Leftover, Manual, Forbidden }`
   - `Recovery { Regenerable, IrreversibleFile, Quarantine, IrreversibleCommand, None }`
   - `Category { System, Browser, Dev, App, Leftover, UserData, Program }`
   - `Phase { Analysis, M3a, M3b, M4, M5a, M5b }`
   - `KnownRoot { LocalAppData, RoamingAppData, Profile, Documents, Downloads, ProgramData, Windows, SystemDrive }`
2. `rules/catalog.rs`：
```rust
pub struct Rule { pub id: &'static str, pub name: &'static str, pub description: &'static str, pub category: Category,
  pub tier: Tier, pub recovery: Recovery, pub phase: Phase, pub admin: bool, pub default_selected: bool,
  pub processes: &'static [&'static str], pub layout_markers: &'static [&'static str] /*相对 root，必须全部存在*/,
  pub warning: Option<&'static str>, pub target: Target }
pub enum Target {
  Paths { root: KnownRoot, rels: &'static [&'static str], selector: Selector },
  ChromiumProfiles { root: KnownRoot, user_data: &'static str, leaves: &'static [&'static str], root_leaves: &'static [&'static str] },
  Adapter(AdapterId), Command(CommandId), Special(SpecialId), System(SystemOpId) }
pub struct Selector { pub kind: SelectKind, pub min_age_hours: Option<u32>, pub exclude_newest_per_dir: bool }
pub enum SelectKind { AllContents /*递归所有文件，以及会变空的子目录*/, TopFiles(&'static [&'static str]) /*只匹配锚点下一层的文件名*/, ChildDirs(&'static [&'static str]) /*锚点下一层匹配的子目录整棵*/ }
pub const ENABLED_PHASES: &[Phase] = &[];
pub fn catalog() -> &'static [Rule];
```
   - `rels` 和匹配模式支持在单个组件内使用 `*` 和 `?`，比较时不区分大小写。
   - 文件年龄 = now − max(CreationTime, LastWriteTime)。
   - `exclude_newest_per_dir`：每个目录中 LastWriteTime 最新的那个文件始终保留。
   - `AdapterId`、`CommandId`、`SpecialId`、`SystemOpId` 先定义成 enum，列出 §4 中对应的全部项。这类规则的候选状态返回 `PhaseLocked`。
3. **规则内容**：逐行对照 `plan-final.md` §4。具体约定如下：
   - Edge、Chrome 各一条 `ChromiumProfiles` 规则，leaves 为 `Cache`、`Code Cache`、`GPUCache`（safe，M3a）。Profile 列表从 `<user_data>\Local State` 的 `profile.info_cache` 键中读取。
   - 再分别为 Edge、Chrome 各加一条着色器规则：root_leaves 为 `GrShaderCache`、`ShaderCache`（caution，M3b）。
   - 缩略图：`TopFiles(["thumbcache_*.db","iconcache_*.db"])`。
   - 应用日志按应用拆成 4 条（微信、QQ、钉钉、WPS），最小年龄 168 小时，`exclude_newest_per_dir: true`。
   - QQ/QQEX 使用 `layout_markers`。进程名：`QQ.exe`、`QQEX.exe`；微信 `Weixin.exe`、`WeChat.exe`；钉钉 `DingTalk.exe`；WPS `wps.exe`、`et.exe`、`wpp.exe`、`wpspdf.exe`、`wpscloudsvr.exe`；Edge `msedge.exe`；Chrome `chrome.exe`；Quark `quark.exe`；Cargo `cargo.exe`、`rustc.exe`。
   - manual 行一律写成 `Phase::Analysis` + `Recovery::None`，只用于展示大小。
4. `rules/forbidden.rs`：
   - `forbidden_roots() -> Vec<(KnownRoot, &str)>`，按 §4 forbidden 行列出。`Windows` 整体禁止；Program Files 和 Program Files (x86) 用 known folder；OneDrive 用 `FOLDERID_SkyDrive`，解析失败时忽略。
   - `forbidden_names() -> &[&str]`：`db_storage`、`msg`、`nt_db`、`IndexedDB`、`Local Storage`、`WPS Cloud Files`。任何路径组件等于其中之一（不区分大小写）都视为禁区。
   - 另外具体禁止 `QQ\auth`、`QQ\security`、`Kingsoft\office6\backup` 和 `<LocalAppData>\CClear`。
   - 含义：forbidden 只禁止执行和迁移，分析时仍然可以显示。
5. `win/process.rs`：`running_processes() -> Vec<ProcInfo { pid, name, image_path: Option<PathBuf> }>`，基于 Toolhelp32 和 `QueryFullProcessImageNameW`，失败的项 image_path 为 None。
6. `rules/resolve.rs`：
```rust
pub struct RootMap { /* KnownRoot -> PathBuf */ } impl RootMap { pub fn system() -> Result<Self>; pub fn with(map) -> Self /*测试注入*/ }
pub enum CandidateStatus { Ready, NotPresent, ProcessRunning(Vec<String>), LayoutMismatch(String), PhaseLocked(Phase), Forbidden(String), Insufficient(String) }
pub struct Candidate { pub rule_id: &'static str, pub status: CandidateStatus, pub anchors: Vec<PathBuf>, pub size: SizeInfo, pub samples: Vec<PathBuf> /*最多 20 个，按大小降序*/, pub executable: bool }
pub fn resolve_anchors(rule: &Rule, roots: &RootMap) -> Vec<PathBuf>;
pub fn evaluate(rule: &Rule, roots: &RootMap, procs: &[ProcInfo], now: SystemTime) -> Candidate;
```
   - 大小统计复用 `scan::scan`，选择器通过 `file_filter` 实现。
   - `executable = tier ∈ {Safe, Caution, Leftover} && phase ∈ ENABLED_PHASES && status == Ready`。
   - 锚点落在 forbidden 内（按路径组件、不区分大小写比较）时，状态为 `Forbidden`。
7. Tauri 命令：`rules_catalog()` 和 `rules_evaluate() -> Vec<CandidateDto>`（后者用 `spawn_blocking` 在后台执行）。前端只需要在 `api.ts`、`types.ts` 中加上类型化封装，页面在 T05 实现。

## 不要做
不实现适配器、命令和特殊操作的具体逻辑，不做执行，不做页面。

## 必须编写的测试（`tests/rules.rs`，RootMap 注入 tempdir）
1. 目录完整性：所有 id 唯一；tier 为 Safe/Caution/Leftover 的 Paths 和 ChromiumProfiles 规则，解析出的锚点都不落在 forbidden 内。
2. Chromium：伪造 `Local State`（含 `Default` 和 `Profile 1`），断言两个 Profile 的 leaves 都被解析出来。
3. 年龄过滤 + `exclude_newest_per_dir`：用 `File::set_times`（含 `FileTimesExt::set_created`）构造文件时间，断言只统计了应该统计的文件。
4. 组件内通配符 `users\*\Cache` 可以正确展开。
