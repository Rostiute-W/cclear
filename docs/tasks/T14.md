# T14 提权 helper 与 ProgramData 残留

- 里程碑：M5
- 依赖：T13

> 执行者先阅读仓库根目录的 `AGENTS.md`。本文件之外的需求一律不做。

## 目标
需要管理员权限的操作由同一个 exe 以 helper 模式执行：只接受内置操作 ID，所有路径和规则由 helper 自己解析。

## 实现要点
1. `elevation/`：
   - `enum SystemOp { LeAppStoreCicada, NvidiaOta, WindowsTemp, WindowsLogs, SysReset, DismAnalyze, DismComponentCleanup, DeliveryOptimization, RestoreBatch(Uuid), PurgeBatch(Uuid) }`，字符串形式为 kebab-case，Batch 类写成 `restore-batch:<uuid>`。
   - `parse_helper_args(args) -> Result<HelperArgs>`。命令行格式：`cclear.exe --elevated --ops <op1,op2> --result <path> [--progress <path>] [--quarantine-root <X:\CClearQuarantine>]`。
     - op 未知或重复时拒绝
     - result 和 progress 路径必须匹配 `^[A-Za-z]:\\Users\\[^\\]+\\AppData\\Local\\CClear\\elevated\\[0-9a-f-]{36}\.(json|progress)$`
     - quarantine-root 必须匹配 `^[A-Z]:\\CClearQuarantine$`，并且是固定 NTFS 的非系统卷
   - `src-tauri/src/main.rs`：参数中带 `--elevated` 时调用 `elevation::helper_main`，执行完退出，不创建窗口。helper 必须确认自己处于提权状态，否则退出。
   - helper 用 Known Folder（ProgramData、Windows）自己解析系统路径，不读取环境变量。
   - helper 使用的 Forbidden：在目录规则的 forbidden 基础上去掉 `Windows` 根目录，同时显式加入 `Windows\System32`、`SysWOW64`、`WinSxS`、`Installer`、`servicing`、`System32\DriverStore`。
   - `run_elevated(ops, quarantine_root) -> Result<HelperResult>`：用 `ShellExecuteExW`（verb 为 "runas"，lpFile 为当前 exe，带 `SEE_MASK_NOCLOSEPROCESS`）启动，在后台线程等待进程结束，然后读取 result 文件。用户取消 UAC（`ERROR_CANCELLED`）时返回“已取消授权”。
   - helper 在 `<ProgramData>\CClear\journal` 写自己的日志（目录不存在时创建）。
2. M5a 操作：
   - `LeAppStoreCicada`：`ProgramData\Lenovo\LeAppStore\cicada` 目录下的内容
   - `NvidiaOta`：`ProgramData\NVIDIA Corporation\NVIDIA App\UpdateFramework\ota-artifacts` 目录下的内容
   - 两者都用隔离引擎处理（隔离根目录由参数传入）
   - 有运行中进程的映像路径位于目标目录下时跳过；另外先**只读**核实联想应用商店和 NVIDIA App 主进程的实际 exe 名，它们在运行时也跳过，核实依据写在注释中
   - helper 创建的批次在 manifest 中标记 `requiresAdmin`；在隔离区页还原或彻底删除这类批次时，通过 `RestoreBatch` / `PurgeBatch` 操作交给 helper 执行
3. 这些规则的候选评估在普通权限下进行（只读大小）。清理页的残留组中，这些行带“需要管理员”标识，执行时只弹出一次 UAC。

## 不要做
不提权运行任何开发工具命令；helper 不接受路径类参数（只接受上面格式固定的三种路径）。

## 必须编写的测试（`tests/elevation_args.rs`）
1. 表驱动测试：合法参数被接受；未知 op、重复 op、不符合模式的 result 路径、带 `..` 的路径、不合法的 quarantine-root 都被拒绝。
