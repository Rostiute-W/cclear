## 实现要点

### A. 设置页
1. 侧栏新增“设置”页（放在“历史”下面，新建 `src/pages/Settings.tsx`，图标沿用 `components/Icons.tsx` 的线条风格新画一个齿轮）。
2. “AI 咨询”卡片：
   - 三个输入框：服务地址（占位文字 `https://api.deepseek.com/v1`）、模型名（占位文字 `deepseek-chat`）、API Key（`type="password"`）。
   - Key 输入框：已保存过 Key 时显示占位文字“已保存（留空表示不修改）”，旁边一个“清除 Key”按钮。保存时输入框为空就传 `null`（保留），点了清除就传 `""`。
   - “保存”按钮；保存成功或失败用现有 `AlertBanner` 提示，错误文字直接显示后端返回的中文信息。
   - 卡片里固定显示说明：“只在你点击‘问 AI’时才联网，请求只发往上面填写的地址。发送前会把用户目录替换为 %USERPROFILE%、把用户名替换为 <用户名>。API Key 用 Windows 加密保存，只有当前 Windows 账号能解开。AI 的回答仅供参考，不会自动执行任何清理。”
   - 说明里列出支持 OpenAI 兼容接口的例子：DeepSeek、通义千问、Kimi、硅基流动、OpenRouter、本地 Ollama（`http://localhost:11434/v1`）。

### B. 清理页“问 AI”
3. 清理页每个分组表格（安全、谨慎、残留、仅分析/手动、不可撤销命令、系统维护等所有规则行）的操作列加一个“问 AI”链接按钮，样式与“检查占用”“打开位置”一致。
4. 点击后在该行下面展开一个子行（沿用现有 `sub-row` 样式）：
   - 一个可选的补充问题输入框（占位文字“可选：补充你想问的，例如‘我还在用 VS Code，能删吗？’”）和“发送”按钮。
   - 发送中显示“正在询问 AI…”，按钮禁用。同一时间只允许一个提问在进行。
   - 回答用 `white-space: pre-wrap` 原样显示纯文本（**不要**把回答当 HTML 或 Markdown 渲染，不要 `dangerouslySetInnerHTML`），上方标注模型名和“仅供参考”。
   - 一个可折叠的“查看发送内容”，显示后端返回的 `sent` 原文。
   - 没有配置 AI 时，后端会报错；子行里显示错误，并给一个“去设置”按钮跳到设置页。
5. AI 的回答不改变任何勾选、按钮可用状态或分级显示。

### C. 文档
6. 根目录 `README.md`：功能列表加一条“AI 咨询”；“已知限制”或隐私说明里写明：使用 AI 咨询时规则信息和脱敏后的路径会发给用户自己配置的服务商；不使用时不联网。

## 不要做
不改后端；不改 `api.ts`/`types.ts` 已有签名（T20a 新增的可以直接用）；不新增依赖；不删除或弱化任何确认与警告文字；不在界面上显示或回填明文 Key。
