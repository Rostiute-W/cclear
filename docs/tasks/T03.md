# T03 扫描接入界面（总览与空间分析列表）

- 里程碑：M1
- 依赖：T02

> 执行者先阅读仓库根目录的 `AGENTS.md`。本文件之外的需求一律不做。

## 目标
用户可以在界面中扫描 C 盘或用户目录，查看进度、取消扫描，并逐级查看目录和 Top 文件。

## 实现要点
1. `guard/external.rs`：`pub fn validate_external_path(s: &str) -> Result<PathBuf, GuardError>`。
   - 只接受 `X:\...` 形式的绝对路径。
   - 拒绝以下情况：以 `\\` 开头（UNC、`\\?\`、`\\.\` 和 GLOBALROOT）；第 2 个字符之后出现 `:`（ADS）；含 `.` 或 `..` 组件；含 `* ? " < > |` 或控制字符；组件以空格或点结尾。
   - 返回规范化路径：统一用反斜杠，去掉重复分隔符和末尾的分隔符（盘符根目录保留 `X:\`）。
2. `win/volume.rs`：`list_fixed_volumes() -> Vec<VolumeInfo { root, label, fs, total, free, is_system }>`，用到 `GetLogicalDriveStringsW`、`GetDriveTypeW == DRIVE_FIXED`、`GetVolumeInformationW`、`GetDiskFreeSpaceExW`；系统盘根据 `known_folder(Windows)` 所在卷判断。`free_space(path) -> u64`。
3. `exec/command.rs`：`open_in_explorer(path: &Path)`，执行 `<Windows 目录>\explorer.exe /select,"<path>"`，explorer 用绝对路径，不等待进程结束。
4. Tauri 命令（`src-tauri/src/commands/scan.rs`；AppState 在 `state.rs` 中，用 `Mutex<Option<Arc<ScanResult>>>` 保存最近一次结果）：
   - `volume_info()`
   - `default_scan_roots() -> [{label, path}]`：返回“C 盘”(C:\) 和“用户目录”(Profile)
   - `scan_start(root: String, onProgress: Channel<ScanProgressDto>) -> Result<String /*scanId*/>`：先 `validate_external_path`，然后在后台线程扫描，每 200 ms 通过 Channel 推送一次进度，结束时推送 `done`
   - `scan_cancel()`
   - `scan_summary()`
   - `scan_children(nodeId: Option<u32>) -> Vec<DirNodeDto { id, name, logical, allocated, files, denied, reparseSkipped, hasChildren, percentOfParent }>`：传 None 时返回根节点
   - `scan_top_files(limit) -> Vec<FileEntryDto { index, path, logical, allocated, lastWrite }>`
   - `open_node_in_explorer(nodeId)` 和 `open_top_file_in_explorer(index)`：参数只接受 ID，路径从扫描结果中取
   按 AGENTS.md 规则 8 同步修改四处。
5. 总览页：
   - C 盘环形图（SVG，已用/剩余）和其他固定卷的条形列表
   - “扫描 C 盘”“扫描用户目录”两个按钮
   - 扫描中显示目录数、文件数、已统计大小、耗时和“取消”按钮
   - 扫描完成后显示摘要；有拒绝访问时提示“N 个目录无权读取（普通权限扫描不完整）”
6. 空间分析页：
   - 目录表：面包屑逐级进入；列为名称、占盘、逻辑大小、文件数、占父目录比例条、标记（无权读取 / 已跳过链接）；每行有“打开位置”
   - “Top 文件”页签
   - 没有扫描结果时，引导用户去总览页扫描

## 不要做
不做 treemap（T08），不做规则相关功能。

## 必须编写的测试（`tests/external_path.rs`）
1. 表驱动测试：至少 6 条合法路径（含盘符根目录、中文、长路径）和至少 10 条非法路径（UNC、`\\?\`、`\\.\`、ADS、`..`、`.`、相对路径、通配符、末尾点、末尾空格），断言结果和规范化输出。
