# T15 系统维护操作

- 里程碑：M5
- 依赖：T14

> 执行者先阅读仓库根目录的 `AGENTS.md`。本文件之外的需求一律不做。

## 目标
在 helper 中实现 Windows\Temp、Windows\Logs、$SysReset、DISM 组件存储分析与清理，以及 Delivery Optimization 缓存清理。

## 实现要点
1. 文件类操作（在 helper 内构建冻结清单，走 guard 和执行器，Recovery 为 IrreversibleFile）：
   - `WindowsTemp`：`<Windows>\Temp` 下 max(ctime, mtime) ≥ 7 天的文件
   - `WindowsLogs`：`<Windows>\Logs` 下递归查找扩展名为 .log、.etl、.cab 且 ≥ 30 天的文件
   - `SysReset`：`<SystemDrive>\$SysReset` 下的全部内容（锚点本身是 reparse point 时拒绝）
   - 被占用的文件跳过
2. DISM（使用绝对路径 `<System32>\Dism.exe`，所有调用都加 `/English`）：
   - `DismAnalyze`：`/Online /Cleanup-Image /AnalyzeComponentStore`，解析出 Actual Size、Reclaimable Packages、Cleanup Recommended
   - `DismComponentCleanup`：`/Online /Cleanup-Image /StartComponentCleanup`，**不加 /ResetBase**；从输出中解析 `[==  xx.x%  ]` 形式的百分比，写入 progress 文件（JSON lines），主进程每秒轮询一次并显示
   - 这个过程无法取消，界面提示“可能需要 10–30 分钟，请勿关机”
3. `DeliveryOptimization`：执行 `<System32>\WindowsPowerShell\v1.0\powershell.exe -NoProfile -NonInteractive -Command "Delete-DeliveryOptimizationCache -Force"`，记录执行前后的剩余空间。
4. 所有外部进程都通过 `exec::command::run` 或 `elevation/` 内的封装启动，可执行文件一律用绝对路径。
5. 清理页新增“系统维护（需要管理员）”分组：
   - “分析组件存储（只读）”按钮，显示分析结果
   - 可以勾选多项，一次 UAC 全部执行
   - 执行后显示每项的结果

## 不要做
不使用 /ResetBase；不手动删除 SoftwareDistribution、WinSxS 或 DO 的私有目录；不停止任何服务。

## 必须编写的测试
无。
