## 目标
完成 M1：清理页能看到全部候选及其状态，可以按需检查占用；总览页显示环境状态卡。全程只读。

## 实现要点
1. `win/restart_manager.rs`：`query_lockers(files: &[PathBuf]) -> LockReport { checked: usize, total: usize, complete: bool, lockers: Vec<Locker { pid, app_name, service: Option<String> }>, error: Option<String> }`。
   - 流程：`RmStartSession` → 每 64 个文件调用一次 `RmRegisterResources` → `RmGetList`（遇到 `ERROR_MORE_DATA` 时扩容重试）→ `RmEndSession`。
   - 任何一步出错都设置 `complete = false` 并记录 error，**不能把出错当作没有占用**。
2. 候选的占用检查：取该候选按大小降序的前 256 个文件进行检查（不足 256 时全部检查），`checked < total` 时也设置 `complete = false`。
3. `envstate.rs`：`env_state() -> EnvState`，包含以下内容：
   - 休眠：注册表 `HKLM\SYSTEM\CurrentControlSet\Control\Power\HibernateEnabled`
   - pagefile：注册表 `...\Session Manager\Memory Management\PagingFiles`
   - WSL 发行版：`HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\*` 中的 `DistributionName` 和 `BasePath`
   - Desktop、Documents、Downloads、Pictures、Videos 的 Known Folder 路径，以及是否在 C 盘
   - OneDrive 路径
   注册表读取放在 `win/registry.rs`。读取失败的项显示“未知”。
4. Tauri 命令：`env_state()`、`candidate_locks(ruleId)`、`open_candidate_in_explorer(ruleId, sampleIndex: Option<u32>)`。
5. 清理页：
   - 按 tier 分组：安全、谨慎、残留、手动、禁区。禁区组默认折叠，只列出名称和原因。
   - 每行显示：名称、占盘大小、状态徽标（可执行 / 进程运行中：xxx / 未找到 / 布局不符 / 将在 Mx 开放 / 证据不足 / 禁区）、说明、warning，以及可展开的样例路径。
   - 每行有“检查占用”按钮：异步查询，显示占用进程，或者显示“本次未发现占用（检测 x/y 个文件）”/“检测不完整：原因”。
   - 每行有“打开位置”按钮。
   - 顶部有“重新评估”按钮，并显示评估耗时。
   - 勾选框先全部禁用，提示“执行功能在后续任务开放”。
6. 总览页加入环境状态卡，以“已在其他盘 / 在 C 盘”的方式展示各项。
