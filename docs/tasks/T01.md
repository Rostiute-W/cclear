# T01 工程骨架

- 里程碑：M0
- 依赖：无

> 执行者先阅读仓库根目录的 `AGENTS.md`。本文件之外的需求一律不做。

## 目标
搭建一个可以启动的 Tauri 2 应用骨架：Cargo workspace、空的 core crate、6 个页面的导航占位，以及一个 `app_info` 命令。

## 实现要点
1. 在**仓库外**的 `%TEMP%` 子目录中，用 `npm create tauri-app@latest` 生成 react-ts 模板（用非交互参数，例如 `-- --template react-ts --manager npm --identifier com.zhuanz.cclear --yes`；参数不被支持时先查 `--help`）。只把这些文件复制到仓库根目录：`package.json`、`index.html`、`vite.config.ts`、`tsconfig*.json`、`public/`、`src/`、`src-tauri/`（含 `icons/`）。然后删掉模板里的示例代码（greet 等）。
2. 删除模板自带的 `tauri-plugin-opener`，包括 Cargo 依赖、npm 依赖 `@tauri-apps/plugin-opener` 和 capability 中的引用。只保留 `@tauri-apps/api` 和 dev 依赖 `@tauri-apps/cli`。在 `package.json` 里保留 `"tauri": "tauri"` 脚本。
3. 根目录 `Cargo.toml`：`[workspace]`，members 为 `crates/cclear-core` 和 `src-tauri`，resolver = "3"；`[workspace.package] edition = "2024"`；在 `[workspace.dependencies]` 中统一声明 AGENTS.md 允许的依赖版本；`[profile.release]` 设置 `lto = "thin"`。
4. `crates/cclear-core`：按 AGENTS.md §1 创建所有模块文件，每个文件里只写一行模块文档注释，`lib.rs` 中声明这些模块。现在只实现两个函数：
   - `win::known_folder(id: KnownFolder) -> Result<PathBuf>`，基于 `SHGetKnownFolderPath`，enum 先包含 LocalAppData、RoamingAppData、Profile、Documents、Downloads、ProgramData、Windows、ProgramFiles、ProgramFilesX86
   - `win::is_elevated() -> bool`，基于 `GetTokenInformation(TokenElevation)`
5. `src-tauri`：package 名 `cclear-app`，二进制名 `cclear`。`tauri.conf.json` 设置如下：
   - productName "CClear"，identifier "com.zhuanz.cclear"
   - `app.windows: []`（窗口在代码中创建），`app.withGlobalTauri: false`
   - `app.security.csp` = `default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:`
   - build：frontendDist "../dist"，devUrl "http://localhost:1420"，beforeDevCommand "npm run dev"，beforeBuildCommand "npm run build"
6. 在 `setup` 中用 `WebviewWindowBuilder::new(app, "main", WebviewUrl::default())` 创建窗口：标题 "CClear — C 盘清理"，尺寸 1280×820，最小 1000×680，`.data_directory(<LocalAppData>\CClear\webview)`。
7. `build.rs` 使用 `tauri_build::try_build(Attributes::new().app_manifest(AppManifest::new().commands(&["app_info"])))`。删除模板的 `capabilities/default.json`，新建 `capabilities/main.json`：`{"identifier":"main","windows":["main"],"permissions":["allow-app-info"]}`。权限标识符的写法以 Tauri 实际生成的为准。
8. 命令 `app_info() -> AppInfo { version, isAdmin }` 放在 `src-tauri/src/commands/app.rs`。
9. 前端：
   - `App.tsx`：左侧导航 6 页（总览、清理、空间分析、隔离区、迁移、历史），每页先用占位组件显示“将在 Txx 实现”。
   - 顶栏显示版本号，以及“普通权限”或“管理员”徽标。
   - `api.ts` 封装 `appInfo()`，`types.ts` 定义 `AppInfo`，`styles.css` 提供简洁的浅色布局。
   - Vite 端口固定为 1420（strictPort）。

## 不要做
不写任何业务逻辑，不写测试，不添加 AGENTS.md 之外的依赖。
