- 用户已明确授权本任务的推送与删除。AGENTS.md 规则 9“不推送”对本任务不适用，仅限下面写明的操作。

## 背景
项目已完成，用户要把仓库推到自己的 GitHub 私有仓库，然后删除本地项目释放空间，只保留已安装的应用。

- 远程仓库：`https://github.com/Rostiute-W/cclear.git`（用户已建好的空私有仓库）
- 只推 `main` 分支。`ui/*`、`agent/dsh-*` 都已合并进 main，不推。
- 本机没有 gh 命令行。Git Credential Manager 2.8 已安装：第一次推送时可能弹出浏览器窗口，需要用户登录 GitHub 授权。弹窗时告诉用户并等待，不要反复重试。

## 绝对不能动的位置
- `E:\CClear`（已安装的应用）
- `%LOCALAPPDATA%\CClear`（设置、操作日志、迁移记录、WebView 数据）
- `D:\CClearQuarantine`（隔离区数据）
- `C:\Users\ZhuanZ\AppData\Local\CodexDshBridge` 下除第 C 节第 2 步列出的工作区以外的任何内容

## A. 推送（交给 DSH）
用 codex-dsh-bridge 提交一个任务（requestId `cclear-T21-r1`），让 DSH 依次执行：
1. `git -C G:\cclear status --short` 必须没有输出。
2. `git -C G:\cclear remote add origin https://github.com/Rostiute-W/cclear.git`（已存在同名 remote 且地址一致就跳过；地址不一致就停下报告）。
3. `git -C G:\cclear push -u origin main`。
4. 不修改任何文件，不新建提交，不推其他分支，不使用 `--force`。

如果桥接工具不支持这种不改代码、只推送的任务（比如强制要求有 diff，或者 DSH 的约束禁止推送），**停下来向用户报告原因**，不要自己改用别的方式推送。

## B. 核对（agy 执行，只读）
1. `git ls-remote https://github.com/Rostiute-W/cclear.git refs/heads/main` 的提交号必须等于 `git -C G:\cclear rev-parse main`。
2. 克隆到临时目录核对：`git clone https://github.com/Rostiute-W/cclear.git G:\cclear-clonecheck`，然后：
   - `git -C G:\cclear-clonecheck rev-parse HEAD` 等于本地 main；
   - `git -C G:\cclear-clonecheck fsck --full` 没有错误；
   - `git -C G:\cclear-clonecheck ls-files` 的数量等于 `git -C G:\cclear ls-files` 的数量。
3. 核对完删除 `G:\cclear-clonecheck`。
4. **任何一项不一致就停下报告，不进入 C 节。**

## C. 清理本地（agy 执行，B 节全部通过之后）
1. 确认没有从 `G:\cclear-target` 运行的进程（`tauri dev`、`cclear.exe`、`cclear-verify.exe`、`node`）。只看路径在 `G:\cclear-target` 或 `G:\cclear` 下的进程；`E:\CClear\cclear.exe` 不要动。
2. DSH 任务工作区：对 `git -C G:\cclear worktree list` 中除 `G:/cclear` 以外的每一项执行 `git -C G:\cclear worktree remove --force <路径>`，最后 `git -C G:\cclear worktree prune`。这些路径都在 `C:\Users\ZhuanZ\AppData\Local\CodexDshBridge\tasks\<id>\workspace`；只删 `workspace`，不删任务目录里的其他文件。
3. 把自己的工作目录切到 `G:\`，然后按顺序删除：`G:\cclear-verify`、`G:\cclear-target`、`G:\cclear`（`Remove-Item -LiteralPath <路径> -Recurse -Force`）。
4. `G:\cclear` 最外层文件夹可能因为被其他进程当作工作目录而删不掉：这种情况下只要里面已经清空就算完成，在报告里说明，留给用户重启后手动删除。
