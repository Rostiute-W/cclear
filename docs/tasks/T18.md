# T18 界面视觉与应用图标重做（agy 亲手实现）

- 里程碑：收尾
- 依赖：T17c
- 执行者：**agy 本人**，不交给 DSH，不使用 codex-dsh-bridge
- **完成并合并后暂停（检查点 E），告诉用户“已到达检查点 E，请通知 Droid 审查”**

> 执行者先阅读仓库根目录的 `AGENTS.md`。本任务是例外：由 agy 直接修改原仓库并自行提交，见文末“提交方式”。

## 目标
现有界面功能齐全但不好看。在**不改变任何功能和后端行为**的前提下，重做全部页面的视觉设计，并设计一个新的应用图标。风格由 agy 自定，怎么好看怎么来；做成一个风格统一、看起来像正经桌面软件的界面。

## 范围
- 页面：`src/pages/` 下的 Overview、Space、Clean、Quarantine、Migrate、History；组件 `src/components/PlanPreview.tsx`、`Treemap.tsx`；`src/App.tsx` 的整体布局和导航；`src/styles.css`。
- 可以新增 `src/components/` 下的展示型组件（按钮、卡片、徽标、图标等），可以新增 `src/assets/` 存放本地 SVG。
- 应用图标：`src-tauri/icons/`。
- 窗口：可以调整 `src-tauri/src/lib.rs` 中 `WebviewWindowBuilder` 的初始尺寸、最小尺寸和标题，除此之外不改这个文件。

## 设计要求
1. 风格统一：颜色、间距、圆角、字号、阴影用 CSS 变量集中定义。推荐同时支持浅色和深色（跟随 `prefers-color-scheme`），不强制。
2. 字体只用系统字体栈（如 `"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", sans-serif`）。**不得加载任何外部字体、图片、CDN 或网络资源**（CSP 是 `default-src 'self'`）。图标用手写的内联 SVG 或 `src/assets/` 中的本地 SVG。
3. 分级要一眼可辨：safe、caution、leftover（隔离）、manual/分析、需要管理员、不可逆操作，各有稳定的颜色和标识，并配文字，不能只靠颜色区分。
4. 危险操作要醒目：永久删除、彻底删除隔离批次、DISM、删除迁移备份等按钮使用警示样式；现有的所有确认框、警告文字、“先预览再执行”的步骤、耗时提示一条都不能删，也不能弱化措辞。
5. 状态完整：加载中、空数据、出错、正在执行（执行锁占用时按钮禁用）都要有清楚的样式。
6. 在 1100×720 的窗口下所有页面可用、不出现横向滚动条；更大窗口下布局合理利用空间。
7. 键盘焦点可见；文字与背景对比度足够阅读。
8. 大小显示保持 `x.xx GB / MB`（二进制单位）格式，界面文字全部中文。

## 应用图标
9. 设计一个与“C 盘清理”主题相符、在 16×16 下仍可辨认的图标。源文件保存为 `src-tauri/icons/icon-source.svg`（1024×1024）。
10. 用本地 CLI 生成各尺寸：`npx tauri icon src-tauri/icons/icon-source.svg`（`@tauri-apps/cli` 已在 devDependencies 中，不联网）。只保留 `tauri.conf.json` 的 `bundle.icon` 引用的文件以及现有的 `Square*Logo.png`、`StoreLogo.png`、`icon.png`；命令额外生成的 `android/`、`ios/` 等目录删除。

## 不要做
- 不改 `src/api.ts`、`src/types.ts`，不改任何 Rust 代码（第“范围”中 `lib.rs` 的窗口参数除外），不改 `build.rs`、`capabilities/`、`tauri.conf.json`。
- 不删除或合并任何功能、按钮、确认步骤；不改变按钮的禁用条件和调用后端的参数；前端仍然只向后端传 ID。
- 不引入 UI 组件库、CSS 框架（含 Tailwind）、路由库、状态管理库、图标库或字体包；不新增任何 npm 依赖。
- 不加动画以外的新交互逻辑。动画要克制，并尊重 `prefers-reduced-motion`。

## 提交方式
1. 开始前确认 `git -C G:\cclear status --short` 为空，然后 `git -C G:\cclear switch -c ui/t18`。
2. 在该分支上完成修改并通过全部验收。用 `git diff --stat main` 确认只改动了“范围”中的文件。
3. 提交：`git -C G:\cclear commit -am`（新增文件先 `git add` 对应路径），提交信息 `feat(ui): redesign pages and app icon`。
4. 合并：`git -C G:\cclear switch main` 后 `git -C G:\cclear merge --no-ff ui/t18 -m "merge: T18 界面视觉与应用图标重做"`。
5. 暂停，在最终说明中列出：设计思路（配色、布局）、改动的文件、验收结果、截图位置、未能做到的设计要求及原因。
